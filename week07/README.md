# week07：RNN 与 LSTM 序列预测

使用 ETTh1 的 `OT` 完成两个实践：先手动展开五步标量 RNN，观察共享参数、状态递推和一次反向传播；再用过去 24 小时预测下一小时，比较隐藏维数 16、32 的单层 LSTM 与两个 week06 基线。另增加同条件 GRU 扩展实验，用于比较两种门控循环结构。

## 环境与运行

- Python 3.12.14
- PyTorch 2.5.1 CPU、NumPy 2.5.4、pandas 3.1.0
- scikit-learn 1.9.1、Matplotlib 3.11.2
- 数据复用 `../week06/data/ETTh1.csv`，来源为 ETT Dataset 的 ETTh1。

在 `week07` 目录运行：

```bash
python run_rnn_trace.py
python run_lstm.py
python run_gru.py
```

三个入口互相独立，导入组件时不会启动实验。`run_lstm.py` 和 `run_gru.py` 分别负责常量配置、遍历两种隐藏维数、选择模型和组装记录；训练、评价和绘图仍由共用组件完成。

## 组件与接口

| 文件 | 职责 |
| --- | --- |
| `data.py` | 读取、检查 ETTh1，构造窗口，按目标时间划分和标准化 |
| `models.py` | 定义 LSTM、GRU，统计参数量，拟合与调用两种基线 |
| `training.py` | 完成 40 轮训练并保留验证 MSE 最小的参数 |
| `evaluation.py` | 完整数据集评价、反标准化预测、计算和复核指标 |
| `reporting.py` | 保存 CSV，绘制损失曲线和验证首周预测图 |
| `run_rnn_trace.py` | 编排五步 RNN 的原顺序、反向传播和顺序对照 |
| `run_lstm.py` | 编排 LSTM 与基线实验，选择模型并保存全部产物 |
| `run_gru.py` | 同条件编排 GRU 与基线实验，结果写入独立目录 |

关键接口是 `train_model(model, train_data, validation_data, ...)`。入口决定训练哪一种模型，训练组件只接收模型和数据，返回历史、最佳参数和最佳轮次。这样 LSTM 和 GRU 共用一条训练流程，入口仍能直接遍历 `16、32`，也不会把评价和绘图混进训练代码。

更细的知识点和逐组件调用过程见 [代码讲解.md](代码讲解.md)，GRU 的结构、代码和实际效果见 [GRU与LSTM对比.md](GRU与LSTM对比.md)。

## 实践一：五步 RNN

最前六个原始油温为 `30.531、27.787、27.787、25.044、21.948、21.174`。固定用第一项作基准后，五步输入为 `0、-0.2744、-0.2744、-0.5487、-0.8583`，目标为 `-0.9357`。

第 2 步的独立核对为：

```text
h[2] = tanh(0.6 × -0.2744 + 0.5 × 0 + 0)
     = -0.163168
```

它与程序记录一致。原顺序末端结果为：

| 项目 | 数值 |
| --- | ---: |
| 预测 | -0.396435 |
| 目标 | -0.935700 |
| 损失 | 0.290806 |
| `wx.grad` | -0.616943 |
| `wh.grad` | -0.293199 |
| `b.grad` | 0.926310 |

五个输入梯度依次为 `0.014993、0.029987、0.061613、0.130850、0.318343`。损失只在末端计算，但第一步仍有梯度，因为依赖链是 `z[1] → h[1] → ... → h[5] → 预测 → 损失`。同一 `wh` 在多个时间步反复使用，所有位置的贡献汇集到同一个 `wh.grad`。

顺序对照 `[1,4,3,2,5]` 的第 2 步状态为 `-0.317820`，原顺序第 2 步状态为 `-0.163168`。到第 5 步时，两组当前输入都为 `-0.8583`，但上一状态分别为 `-0.421819` 和 `-0.310408`，所以最终预测分别为 `-0.396435` 和 `-0.368081`。顺序影响通过上一隐藏状态进入下一步计算。

## 实践二：LSTM

使用前 14,400 行；先构造窗口，再按目标时间划分。训练、验证、测试样本数分别为 `8616、2880、2880`。标准化统计量只来自原始训练时段内每个 OT 观测一次：`μ=17.128262`，总体标准差 `σ=9.176491`。

训练前使用同一批 128 条实际样本检查形状：

| 隐藏维数 | 输入 | 每步输出 | `h_n` | `c_n` | 预测 | 参数量 |
| ---: | --- | --- | --- | --- | --- | ---: |
| 16 | `(128,24,1)` | `(128,24,16)` | `(1,128,16)` | `(1,128,16)` | `(128,1)` | 1,233 |
| 32 | `(128,24,1)` | `(128,24,32)` | `(1,128,32)` | `(1,128,32)` | `(128,1)` | 4,513 |

本实验是单层、单向 LSTM，因此 `output[:, -1, :]` 与 `h_n[0]` 实际核对相等。代码选择前者作为末步表示，再送入线性层得到 `(128,1)` 的下一小时预测。`c_n` 保存经过保留与写入后的细胞状态；`h_n` 是经过输出门和 `tanh` 后对外提供的表示，二者形状相同但含义不同。

## 结果与选择

LSTM 的选择只看恢复最佳参数后的原始尺度验证 RMSE；完全相同才优先隐藏维数 16。

| 模型 | 最佳轮次 | 训练 RMSE | 验证 RMSE | 测试 RMSE |
| --- | ---: | ---: | ---: | ---: |
| last_value | — | 1.066672 | 0.925271 | 0.592978 |
| lag_linear | — | 1.043134 | **0.910183** | **0.584538** |
| lstm_h16 | 38 | 1.051687 | 0.914489 | — |
| lstm_h32 | 39 | 1.047373 | 0.914153 | 0.609383 |

`lstm_h32` 的验证 RMSE 略低于 `lstm_h16`，因此被选中并且只有它进入 LSTM 测试评价。两种 LSTM 的验证结果都优于最近值，但略差于线性回归；选中 LSTM 的测试结果也没有超过两个基线。这个结果说明模型确实学到了可用于预测的序列表示，但不能据此声称它比简单方法更适合当前数据，更不能仅凭误差判断它学到了长距离依赖。

具体看首条验证目标：2017-06-26 00:00 的真实 OT 为 `20.962999`。它的窗口是 2017-06-25 00:00 至 23:00 的 24 个真实观测；`lstm_h32` 依次读入标准化值，把末步 32 维隐藏状态送入线性层，反标准化后的预测为 `20.710532`。同一目标的最近值与线性回归预测分别为 `20.752001`、`20.899998`。

## 结果文件

- `rnn_trace.csv`：原顺序和调整顺序各五步，原顺序含输入梯度。
- `history.csv`：两种 LSTM 各 40 轮的标准化训练、验证 MSE。
- `metrics.csv`：规定模型和数据部分的原始尺度 MAE、RMSE。
- `predictions.csv`：与指标对应的全部逐目标预测，共 54,624 行。
- `loss_curves.png`：两种隐藏维数的训练、验证曲线及最佳轮次。
- `validation_predictions.png`：验证首周的真实值、两个基线和选中 LSTM。
- `selected_lstm.pt`：选中模型参数、隐藏维数、最佳轮次、标准化统计量和窗口长度。

程序从逐行预测重新计算指标，检查 `(model, split, target_index)` 无重复，并核对样本数、MAE 和 RMSE，测试集不参与选型。

## GRU 扩展结果

GRU 严格沿用 LSTM 的数据、24 小时窗口、隐藏维数、40 轮训练、Adam 设置、随机种子和验证集选型规则，结果单独保存在 `results_gru/`。

| 模型 | 参数量 | 最佳轮次 | 训练 RMSE | 验证 RMSE | 测试 RMSE |
| --- | ---: | ---: | ---: | ---: | ---: |
| gru_h16 | 929 | 38 | 1.067797 | 0.927511 | — |
| gru_h32 | 3,393 | 35 | 1.044604 | 0.914367 | 0.625771 |

`gru_h32` 被选中。相同隐藏维数 32 时，它比 `lstm_h32` 少 1,120 个参数，约少 24.8%；验证 RMSE 仅高 `0.000214`，但测试 RMSE 高 `0.016388`。本次结果说明 GRU 用更少参数取得了非常接近的验证表现，但没有在最终测试上超过 LSTM。

`results_gru/` 包含 `history.csv`、`metrics.csv`、`predictions.csv`、两张 PNG 和 `selected_gru.pt`，表结构与 LSTM 结果一致。
