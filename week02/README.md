# gd_bmi.py

> 运行入口为 `python bmi_regression.py`。数据准备、梯度下降、评价和绘图直接保留在一个文件中。

实践二：用 diabetes 数据的**单个特征 bmi** 拟合 `预测值 = w × x + b`，用 NumPy 手写梯度下降，并与库函数、均值基线对比。

## 代码做什么

按实验顺序走完 7 步，全部结果写进 `result/`：

1. **划分**：60% 训练 / 20% 验证 / 20% 测试，`random_state=42`，四个模型共用同一份划分；
2. **标准化**：只用训练集 bmi 的均值、标准差，同一组参数变换三部分；`target` 保持原样；
3. **均值基线**：训练集 target 均值当常数预测，并用 `DummyRegressor(strategy="mean")` 交叉验证；
4. **手写梯度下降**：`w = b = 0` 起步，每轮全量样本，代码里标了 ①预测 ②梯度 ③更新；
5. **比较学习率**：`0.01` 与 `0.1` 各 500 轮，损失曲线画在同一张图（线性 + 对数两个子图）；
6. **与 `LinearRegression` 对照**：权重、截距、训练 MSE、逐条预测值差异；
7. **评价与检查**：训练/验证 MAE、RMSE 定配置 → 锁定后只算一次测试指标；再画真实值-预测值散点图、核对样本。

## 数据从哪里来

`sklearn.datasets.load_diabetes(as_frame=True, scaled=False)`，随 scikit-learn 附带，无需联网。

- 442 行 × 11 列（10 特征 + `target`），本实践只用 `bmi`；
- `scaled=False` 保留原始量纲，所以标准化参数必须自己算（上周的默认 `True` 已经帮你缩放过了）。

## 实测结果

| 模型 | 训练 MAE | 训练 RMSE | 验证 MAE | 验证 RMSE | 测试 MAE | 测试 RMSE |
| --- | --- | --- | --- | --- | --- | --- |
| 均值基线 | 64.66 | 77.33 | 67.52 | 76.16 | 66.73 | 76.91 |
| 梯度下降 lr=0.01 | 50.95 | 61.45 | 49.20 | 60.83 | — | — |
| 梯度下降 lr=0.1 | 50.95 | 61.45 | 49.21 | 60.83 | 55.21 | 67.04 |
| LinearRegression | 50.95 | 61.45 | 49.21 | 60.83 | 55.21 | 67.04 |

`.01` 那一行没有测试指标，因为验证集已经决定用 `0.1`，按规则不再拿另一组去碰测试集。

## 几个关键数字

- 划分：训练 265 / 验证 88 / 测试 89；训练 bmi 均值 26.6113、标准差 4.4416；
- 梯度下降最终参数：`w = 46.9499`、`b = 151.0264`（标准化空间），训练 MSE 3775.76；
- `lr=0.1` 第 16 轮就进入最终损失的 1%，`lr=0.01` 要 162 轮，二者最终解一致；
- 与 `LinearRegression` 的差：`lr=0.1` 为 `Δw ≈ -7e-15`（浮点级），`lr=0.01` 为 `-1.9e-3`；
- 换算回原始量纲：`y = 10.57 × bmi − 130.27`；
- 测试集 RMSE 67.04 高于训练集 61.45，主因是测试集 target 均值比训练集高 11.4，截距锚定在训练均值上导致系统低估约 12.8。

## 结论

bmi 单特征有明显作用（验证 MAE 67.5 → 49.2），但误差仍很大：一个特征解释不了 target 的全部变化。训练损失从 28789 降到 3775 很快，这只说明参数在这 265 条样本上拟合到位，不代表对新样本更准；换一批样本，误差由不可约噪声、分布偏移和模型容量共同决定。
